# Release notes

Overzicht van wijzigingen per versie van de Hasura-plugin.

## 1.2.1
Foutafhandeling verbeterd bij het tracken van tabellen die al door Hasura worden bijgehouden.

## 1.2.0
SQL-statements kunnen nu rechtstreeks in de UI worden opgegeven in plaats van via losse SQL-bestanden.

## 1.1.0
Logo en aanvullende documentatie toegevoegd voor de plugin.

## 1.0.0
Eerste publieke release: Hasura beheren vanuit Valtimo, met onder andere het tracken van tabellen.
